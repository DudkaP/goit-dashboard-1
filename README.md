# Домашка 2 - REST API Дошки оголошень

Це мій проект для другого домашнього завдання по Node.js. Тут зроблено бекенд для дошки оголошень з авторизацією через JWT токени та базою даних через Prisma.

## Що тут є

- Реєстрація та логін користувачів (`/auth/register`, `/auth/login`)
- Оновлення токенів (`/auth/refresh`), вихід (`/auth/logout`) і отримання профілю (`/auth/me`)
- CRUD для оголошень (`/announcements`):
  - перегляд всіх оголошень з пагінацією (по 10 штук), пошуком по назві і сортуванням
  - перегляд одного оголошення по id
  - створення нового оголошення (тільки для залогінених)
  - редагування і видалення (тільки своїх оголошень, чужі не дає)
- Валідація через Zod
- Документація Swagger на `/api-docs`

## Як запустити

1. Встановити пакети:
```
npm install
```

2. Створити файл `.env` (можна скопіювати з `.env.example`) і прописати там базу даних і секрет для токенів:
```
DATABASE_URL=postgresql://postgres:password@localhost:5432/announcements?schema=public
JWT_SECRET=your_secret_key_here
```

3. Запустити міграції Prisma:
```
npm run prisma:migrate
```

4. Запустити сервер:
```
npm run dev
```

Після запуску сервер працює на `http://localhost:3000`, а сваггер можна відкрити на `http://localhost:3000/api-docs`.
